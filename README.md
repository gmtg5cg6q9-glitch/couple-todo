# 我们的小日子 v0.5

保留原站七个入口，补齐真实在线推荐与双人同步。静态站无需构建。

## 使用

1. 打开网站的「设置」。项目地址和前端公开 Key 已自动配置。
2. 第一端点击「生成新空间码」→「连接共享空间」。
3. 将「邀请链接」发给另一半。另一端打开链接，确认「连接共享空间」。也可手动输入同一空间码。
4. 顶部显示「实时连接已建立」；两端同时在线时会显示「TA 也在线」。待办、纪念日、共同想看／看过片单自动刷新。

每个空间绑定两个浏览器身份。请在两个人实际要使用的设备上配对，保留浏览器资料与空间码。不要将邀请链接公开。测试空间与正式使用空间相互独立。

## 数据

- `app-config.json` 仅包含 Supabase 项目 URL 和 publishable Key，是可公开的前端配置。没有管理密钥。
- `setup-supabase.sql` 是新项目初始化脚本。本次已在指定项目执行，Realtime 和匿名设备登录已启用。
- 待办、纪念日和片单保存在已加入的云空间；本机模式独立保存。昵称、开始日期、电影类型偏好和旅行城市仍按设备保存。
- 同一条记录两端离线同时编辑时，后同步的修改覆盖先前值。
- 本机备份不下载云端相册，不包含空间凭证、身份令牌和同步队列。
- 推荐默认来源是美国电影榜，保留原片名与简介语言；配置自己的 TMDB Key 后使用中文热门电影。当前搜索筛选已加载片单。
