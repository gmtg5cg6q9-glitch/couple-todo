## 数据与服务边界

- 本机功能直接可用；离线功能需要首次联网打开且浏览器支持 Service Worker。
- 双人同步及云端相册需要用户自己的 Supabase 项目、表、桶和访问策略。实时同步需为 `couple_rows` 启用 Realtime。没有配置时仅保存本机。
- 原站 SQL 示例允许匿名公开读写，**共享口令不等于身份认证**。正式使用私人数据前需要配置身份认证和 RLS；此前可使用本机模式或非敏感测试数据。本次没有创建、修改云服务或数据库权限。
- 在线推荐需要有效 TMDB Key 和网络；内置推荐与本机片单无需外部服务。
- 昵称、开始日期、城市与影视片单按设备保存，可通过备份迁移。恢复替换备份内对应的本机列表，同标识照片覆盖，其余照片保留。备份不下载云端照片，不包含连接密钥及离线同步队列。
- 截止日期仅在页面显示。后台推送、iOS 灵动岛及网页内嵌微信小程序仍需要对应平台服务或原生应用，本次未实现。
- 同一条云端记录多端离线编辑时，后同步的修改覆盖先前值。删除撤销保留到离开待办页或手动关闭。
